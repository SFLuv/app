# fund-wallet

Puts SFLUV into any wallet on the local fork, by impersonating a holder.
Distinct from fund-faucet, which tops up the payout faucet — this funds a
PERSON's wallet so sends, tips, and merchant payments can be tested from an
account that actually has money.

```
./scripts/fund-wallet/fund-wallet.sh 0xRecipient [whole-sfluv]
```
